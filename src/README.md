# Application Code

This directory contains the application source code for Azure architecture demos.

## Structure

- `.NET/` - .NET application examples
- `Blazor/` - Blazor web applications
- `shared/` - Shared libraries and utilities

## Technologies

- .NET 8.0+
- Blazor WebAssembly / Server
- Azure SDKs
- Entity Framework Core

## Getting Started

Navigate to the specific application directory and follow its README for build and run instructions.

```bash
cd src/<app-directory>
dotnet restore
dotnet build
dotnet run
```

## Development Guidelines

- Follow clean architecture principles
- Implement proper error handling
- Use dependency injection
- Write unit and integration tests
