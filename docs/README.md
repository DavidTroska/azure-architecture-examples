# Documentation

This directory contains architecture documentation, diagrams, and guides.

## Structure

- `architecture/` - Architecture diagrams and design documents
- `guides/` - Step-by-step implementation guides
- `best-practices/` - Azure best practices and recommendations
- `references/` - External references and resources

## Documentation Standards

- Use Markdown for all documentation
- Include diagrams for complex architectures
- Keep documentation up-to-date with code changes
- Provide real-world context and use cases

## Tools

- Draw.io or Visio for architecture diagrams
- Markdown for documentation
- PlantUML for sequence diagrams (optional)
